PiaNewbie
=========

■ 시스템 요구 사항
  - Windows 10 / 11 (64비트)
  - Microsoft Edge WebView2 Runtime
    Windows 11에는 대부분 이미 설치되어 있습니다.
    Windows 10에서 실행이 안 되면 아래에서 설치하세요.
    https://go.microsoft.com/fwlink/p/?LinkId=2124703

■ 지원 파일
  - MIDI 파일 (.mid, .midi)
  - MP3, WAV 는 지원하지 않습니다.

■ 실행이 안 될 때
  1. WebView2 Runtime 설치 여부를 확인하세요.
  2. 64비트 Windows 인지 확인하세요.
  3. zip 으로 받았다면 압축을 풀었는지 확인하세요.
  4. 백신·보안 프로그램이 차단했는지 확인하세요.
  5. 피아노 롤 화면이 비어 있다면 WebView2 설치 후 앱을 다시 실행해 보세요.

■ MIDI 파일 구하기
  앱 MIDI 설정 화면의 "MuseScore에서 찾기" 버튼을 이용하거나
  https://musescore.com/sheetmusic 에서 검색해 보세요.

■ 주의사항
  - 구매·다운로드한 MIDI 파일을 재배포하면 저작권 문제가 될 수 있습니다.
  - 개인 연습 용도로만 사용해 주세요.

■ 단축키
  메인 화면   ESC : 종료
  MIDI 설정   ESC : 메인으로
  연습 중     ESC : 설정으로  /  F5 : 재시작
  결과 화면   ESC : MIDI 설정으로
